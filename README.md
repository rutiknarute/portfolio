# Rutik Narute Portfolio

Fast, responsive portfolio built with Next.js 16, React 19, TypeScript, Tailwind CSS, semantic design tokens, and lightweight CSS 3D.

## Run locally

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Contact delivery

Contact form uses Resend through `app/api/contact`. Copy `.env.example` to `.env.local` and add `RESEND_API_KEY`. Without a key, interface shows direct-email fallback.

## Commands

```bash
npm run typecheck
npm run lint
npm run build
```
